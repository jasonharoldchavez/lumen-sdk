A local-first integrity utility

File Proof

Create a SHA-256 fingerprint for a file, save a small receipt, and later check whether another copy has exactly the same contents.

Your selected file is read inside this browser. This page contains no upload code, analytics, accounts, or external API calls. The file itself is not sent to a server.

1. Create a proof receipt

Choose a file and generate its SHA-256 fingerprint. Save the JSON receipt somewhere separate from the file.

2. Verify a file later

Select the saved receipt and the file you want to check. A match means the file bytes match the recorded fingerprint.

What this proves — and what it does not

SHA-256 is a widely used cryptographic hash function. File Proof compares a newly calculated fingerprint with one saved earlier.

A matching fingerprint is strong evidence that the two files contain the same bytes. It does not prove who created the file, whether the original was truthful, when it was first created, or whether the saved receipt itself is authentic.

For this first release, files are limited to 100 MiB to reduce memory pressure on phones. Keep your receipt private if its filename or other metadata is sensitive.
