# Lumen SDK v0.5.0

## Verifiable Event Ledger and Integrity Framework

Lumen SDK is a Python toolkit for building auditable data systems with cryptographic integrity verification.

## Includes

- Cryptographic event ledger
- Merkle verification
- HMAC integrity checks
- Forensic audit tools
- Validation test suite
- Python package distribution

## Install

pip install lumen-sdk
